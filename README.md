# When Guardrails Fail - Project Website

Static GitHub Pages site for:

**When Guardrails Fail: Multilingual Long-Context Safety in Tool-Using Agents**  
NeurIPS 2026 - Long-Context Foundation Models (LCFM)

## Deploy on GitHub Pages

1. Create a repository, for example `Guardrails-Fail`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. The site will appear at `https://<organization-or-user>.github.io/Guardrails-Fail/`.

## Files

- `index.html` - webpage content
- `styles.css` - responsive styling
- `script.js` - BibTeX copy button
- `assets/` - figures extracted from the paper PDF
